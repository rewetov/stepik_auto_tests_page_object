Это финальный релиз для курса Stepik "Автоматизация тестирования с помощью Selenium и Python". Это проект по автоматизации тестирования веб-сайта интернет-магазина. Тесты проверяют основные действия пользователя: регистрацию, вход в аккаунт, добавление товаров в корзину и корректность отображения цен. В проекте используется популярный паттерн Page Object Model (POM). Это значит, что логика работы сайта и сами тесты разделены, чтобы код было легко читать и обновлять.


Страницы сайта (папка pages):

* BasePage — базовая страница. Содержит общие для всего сайта действия и «умные ожидания» элементов, чтобы тесты не падали из-за долгой загрузки сайта.
* MainPage — главная страница магазина и логика переходов с неё.
* LoginPage — формы регистрации и входа на сайт (проверка создания учётной записи).
* ProductPage — карточка товара (добавление в корзину).
* BasketPage — корзина (проверка пустоты корзины и списка товаров).

Тесты:
* test_main_page.py — проверки переходов с главной страницы.
* test_product_page.py — проверки добавления товаров, работы корзины и успешности авторизации.

Команды запуска тестов:
* "pytest -v --tb=line" - для краткого вывода в лог. По умолчанию запускается в Chrome
* "pytest -v -s --tb=line" - для более подробного вывода в лог
* "pytest -v --tb=line --browser_name=firefox" - для запуска в Firefox
